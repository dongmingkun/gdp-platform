# 手动数据文件目录

公开渠道拿不到的数据可以整理成 CSV 放在这里，然后执行导入：

```bash
python -m spider.manual
```

导入后数据会写进 `region_gdp` 表，**来源标注为 CSV 里的“来源”列**，在页面上与自动采集的数据区分显示。

## 文件格式

| 列 | 必需 | 说明 |
| --- | --- | --- |
| 区域名称 | 是 | 城市 / 省份 / 州 的名称，例如“深圳”“加州” |
| GDP | 是 | 数值。单位默认按**亿元**处理，也可以写在列名里：`GDP(万元)`、`GDP(亿美元)` |
| 上级区域 | 否 | 所属省份，例如“广东”；填了以后可以在“区域对比”页下钻查看 |
| 年份 | 否 | 留空时从文件名里取，例如 `城市GDP_2025.csv` 会识别为 2025 年 |
| 人均GDP | 否 | 人均数值（元） |
| 来源 | 否 | 建议写明，例如“抖音榜单整理（待核对官方公报）” |
| 层级 | 否 | 默认 `city`；省级写 `province`，州写 `state`，县写 `county` |
| 经济体 | 否 | 默认 `CHN`；美国写 `USA`，日本写 `JPN` |
| 货币 | 否 | 默认 `CNY` |

其他要求：

- 编码用 UTF-8（Excel 里“另存为 → CSV UTF-8”即可）；
- 以 `#` 开头的行会被当作注释跳过；
- 文件名以 `模板`、`示例`、`_` 开头的文件不会被导入（方便放样例）。

## 示例

```csv
区域名称,上级区域,年份,GDP(亿元),人均GDP(元),来源
深圳,广东,2025,38000,210000,抖音榜单整理
苏州,江苏,2025,27000,215000,抖音榜单整理
```

> 提醒：来自榜单视频的数字建议与当地统计公报核对一遍，并在“来源”列注明，
> 答辩时也便于说明数据出处。
