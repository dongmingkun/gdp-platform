这个系统解决什么问题

GDP 数据分散在各类官方与财经网站，格式不一、口径不同，想横向比较多个国家几十年的走势， 往往要手工找数据、拼表格、再画图。本系统把「采集 → 清洗 → 入库 → 可视化」串成一条自动流水线： 点一次按钮就能把两个数据源的最新数据抓下来存进数据库，并在网页上直接看排行、趋势、对比与结构变化。

技术路线
Python 3 + requests（爬虫）+ SQLite（数据库）+ Flask/Jinja2（后端渲染）+ ECharts（前端图表）+ Tkinter（桌面采集控制台）

数据源调研记录

原始需求是“中国分省 GDP”，逐个实测后改用上面两个可用数据源
候选数据源实测结果结论
国家统计局 · 国家数据
data.stats.gov.cn/easyquery.htm		 返回 HTTP 403，响应头带 WZWS-RAY 与 reason:UrlACL，属于 WAF 按路径拦截；改用 http 协议、补全浏览器请求头均无效 不可用
中国统计年鉴（分省表）
stats.gov.cn/sj/ndsj/2024/html/C03-09.jpg		 分省数据表全部是扫描图片（525 KB JPEG），页面中不存在对应的 .htm 或 .xls 文件，需要 OCR 才能读取 不可靠，放弃
新浪财经 · 宏观经济
money.finance.sina.com.cn/mac/api		 旧的 JSONP 接口已下线，请求被重定向到财经首页 不可用
东方财富数据中心
datacenter-web.eastmoney.com/api		 可用，但只有全国季度数据，没有分省数据；必须带 Referer 请求头 采用（中国季度）
世界银行开放数据
api.worldbank.org/v2		 可用，覆盖 266 个经济体、{{ year_range[0] }}–{{ year_range[1] }} 年，接口稳定且无需密钥；偶发 SSL 中断可重试成功 采用（各国年度）
调研结论：分省 GDP 在公开渠道上要么被反爬拦截、要么以扫描图片形式发布，短期内无法稳定自动采集， 因此本期以「全球各国 + 中国全国」为数据范围。采集层已按“一个数据源一个类”的方式组织， 后续若找到稳定的分省数据源，只需新增一个 Spider 子类并在调度里注册即可，其余各层无需改动。
