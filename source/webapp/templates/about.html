这个系统解决什么问题

GDP 数据分散在各类官方与财经网站，格式不一、口径不同，想横向比较多个国家几十年的走势， 往往要手工找数据、拼表格、再画图。本系统把「采集 → 清洗 → 入库 → 可视化」串成一条自动流水线： 本地主程序可选择世界银行、东方财富、BEA、维基百科与人工整理文件更新数据；网页提供城市格局、排行、人均、趋势、对比与结构分析。

技术路线
Python 3 + requests（爬虫）+ SQLite（数据库）+ Flask/Jinja2（后端渲染）+ ECharts（前端图表）+ Tkinter（桌面采集控制台）

使用说明与免责声明

本系统为 Python 课程大作业，数据取自上述公开接口，仅供学习与研究使用，不作为投资或决策依据。 世界银行的 GDP 数据按当年汇率折算成现价美元，跨国比较时会受汇率波动影响； 中国季度数据为累计口径（例如“第 1-3 季度”指前三季度累计），网页上的单季值由相邻两期相减得到。 城市人均 GDP 以本币显示，代表人均产出，不能当作居民收入或国际收入等级。 增速平均为有数据样本的简单平均，既不是按 GDP 加权的增速，也不是全国实际增速。
