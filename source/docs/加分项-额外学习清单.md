## 二、按“学了什么”分类的说明（便于口述）

1. **Web 全栈**：从零搭起 Flask 应用——路由与接口分层、请求参数校验、错误处理、模板渲染、静态资源本地化；理解了「服务端渲染 + 异步接口」混合模式为什么比纯前端渲染首屏更快。
2. **数据库**：不只是增删改查——设计了主键与联合主键、按访问模式建索引、用 `ON CONFLICT DO UPDATE` 做幂等写入、用 `RANK() OVER (PARTITION BY year ...)` 一次算出逐年排名。
3. **并发**：线程池适合「大量等待网络的任务」；线程只负责投递消息、界面只在主线程更新，这是 Tkinter 程序的硬性约束。
4. **爬虫工程化**：真正花时间的是异常路径——被限速（429）要按 `Retry-After` 等待、被 WAF 拦截（403）要立刻放弃而不是硬重试、编码声明可能与实际不符。
5. **数据可信度**：对三百多行识别结果做了三重校验（表内三列互算、顺序去重、省级加总核对），这一步让我明白“拿到数字”和“敢用数字”是两件事。
6. **工程习惯**：分层目录、统一配置、单元测试、把「数据来源」写进每一行数据。
7. **部署与运维**：本地跑起来只是第一步——把开发服务器换成 waitress/gunicorn、用 Docker 把环境和数据一起打包、用 Nginx 反向代理、用 systemd 保证崩溃自启、用 certbot 签免费 HTTPS、把域名解析到服务器；还学到一件容易被忽略的事：**公网站点必须按“只读”设计**，否则任何访客都能触发采集，于是加了公共演示模式（页面隐藏入口 + 接口返回 403）。

## 三、如果老师追问“哪些是课上没讲的”

课上通常讲的是 **Python 语言本身**（语法、列表/字典/函数/类、文件读写、异常、标准库基础）。
下面这些超出课堂范围、由本项目自行学习并落地：

Flask、Jinja2、HTTP 接口设计、SQLite 与 SQL 进阶、多线程/线程池、请求重试与限速策略、
HTML 表格解析（lxml/XPath）、ZIP/CSV 批量解析、ECharts、matplotlib、Tkinter GUI、
pytest 单元测试、docx-js 文档自动化、响应式 CSS 与前端交互优化、
生产 WSGI 服务器（waitress/gunicorn）、Docker 容器化、Nginx 反向代理与 HTTPS 证书、
域名解析与 ICP 备案常识、公网只读模式的设计取舍。
