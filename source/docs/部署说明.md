# 部署说明：把平台挂到你自己的域名上

本说明回答一件事：**怎么让同学、老师用 `https://你的域名/` 打开这个平台。**
平台是单机应用（Flask + SQLite + 本地 ECharts），不需要额外的数据库服务，
所以从「只买了域名」到「有一台云服务器」都能部署；下面按你手上有什么，挑一条路线走。

---

## 一、先想清楚两件事

**1）公网版本应该只读。**
本地版本有「一键更新数据」，公网上如果开着，任何人都能用一句 `curl` 触发采集，
把服务器 CPU 和带宽占住，还可能往数据库里写东西。因此部署时打开**公共演示模式**：

```bash
GDP_PUBLIC=1        # 环境变量，平台后台填即可
```

打开后：页面顶部出现「在线演示站点 · 只读快照」提示条；数据集页的采集面板换成只读说明；
`POST /api/crawl/start` 直接返回 403。**浏览、筛选、下钻、导出 CSV 全部照常可用。**

数据要更新时在自己电脑上跑 `python -m spider.pipeline`（或本地点「一键更新数据」），
再重新部署一次，公网快照就刷新了。

**2）域名指向哪里，决定要不要备案。**

| 你的服务器/平台位置 | 是否需要 ICP 备案 |
| --- | --- |
| 中国大陆的云服务器（阿里云 / 腾讯云 / 华为云等） | **需要**，未备案的域名会被 80/443 拦截 |
| 境外服务器（香港、新加坡、日本、美西等） | 不需要 |
| 免费平台（Render / Zeabur / Hugging Face、Cloudflare 隧道等） | 不需要 |

备案在云厂商的控制台里线上提交（个人备案一般 1–3 周），学校项目常见做法是：
先用境外节点或免费平台把域名挂起来给同学看，备案走流程、下来后再切到国内服务器。

---

## 二、三条路线，按条件选一条

### 路线 A：没有服务器 —— 用免费平台 + 自己的域名（最省事，推荐）

以 **Render** 为例（Zeabur、Railway 步骤几乎一样）：

1. 把项目推到 GitHub（新建一个仓库，把 `gdp-platform` 整个目录传上去）。
   注意：`data/gdp.db`（17 MB）与 `data/dataset/`（11 MB）要一起传，
   它们是站点数据本体；`docs/out/pages/` 与 `docs/docbuild/node_modules/` 不用传。
2. Render → **New → Blueprint** → 选这个仓库。它会自动读仓库里的
   [`deploy/render.yaml`](../deploy/render.yaml)，建好一个 Web 服务（免费档即可）。
   构建命令与启动命令已经写在这个文件里，环境变量 `GDP_PUBLIC=1` 也已经设好。
3. 等第一次构建完成，先用平台给的临时域名（`xxx.onrender.com`）打开确认页面正常。
4. **绑定你的域名**：Render 后台 → 你的服务 → **Settings → Custom Domains → Add**，
   填 `gdp.你的域名.com`；平台会告诉你加一条 **CNAME** 记录。
5. 到域名商（阿里云 / 腾讯云 / Namecheap / Cloudflare…）的 **DNS 解析**里加：
   - 记录类型 `CNAME`，主机记录 `gdp`，记录值 = Render 给的目标（形如 `xxx.onrender.com`）
6. 等 DNS 生效（几分钟到一小时），打开 `https://gdp.你的域名.com/`。
   Render 会自动申请 HTTPS 证书，不用自己配。

> 免费档的两个已知代价：实例闲置一段时间会**休眠**，第一位访客打开要等十几秒唤醒；
> 每月有流量额度。给同学看、给老师验收足够。

> 用 **Hugging Face Spaces** 也可以（免费、无需备案）：新建 Space 时选 **Docker** 模板，
> 把 `deploy/Dockerfile` 复制到仓库根目录，并在 Space 的 `README.md` 头部加一行
> `app_port: 8000`，再把项目文件一起传上去即可；绑定自有域名在 Space 的
> Settings → Custom domain 里操作（同样加一条 CNAME）。

### 路线 B：有云服务器 —— Nginx + systemd + 自己的域名（最稳，可长期跑）

假设服务器是 Ubuntu / Debian，域名已解析到这台机器（A 记录 → 服务器公网 IP）：

```bash
# 1. 装依赖（Python 3.9+ 即可）
sudo apt update && sudo apt install -y python3-venv python3-pip nginx

# 2. 把项目传到 /srv/gdp-platform（git clone 或 scp 均可）
sudo mkdir -p /srv && cd /srv
sudo git clone <你的仓库地址> gdp-platform && cd gdp-platform

# 3. 建虚拟环境并装依赖（多装了 waitress：生产级的 WSGI 服务器）
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt -r requirements-server.txt

# 4. 先手动跑一次，确认能起来
GDP_PUBLIC=1 GDP_HOST=127.0.0.1 GDP_PORT=8000 .venv/bin/python wsgi.py
#   浏览器/本机 curl 打开 http://127.0.0.1:8000/ 有页面即正常，Ctrl+C 停掉

# 5. 交给 systemd 托管（开机自启、崩溃自动重启）
sudo cp deploy/gdp-platform.service /etc/systemd/system/
sudo nano /etc/systemd/system/gdp-platform.service   # 核对 WorkingDirectory 与 User
sudo systemctl daemon-reload
sudo systemctl enable --now gdp-platform
sudo systemctl status gdp-platform

# 6. Nginx 反向代理 + 静态文件
sudo cp deploy/nginx.conf.example /etc/nginx/conf.d/gdp.conf
sudo nano /etc/nginx/conf.d/gdp.conf                 # 把 gdp.example.com 换成你的域名
sudo nginx -t && sudo systemctl reload nginx

# 7. 免费 HTTPS 证书（certbot 会自动改好 Nginx 配置）
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d gdp.你的域名.com
```

到这一步，`https://gdp.你的域名.com/` 就是你的平台了。
更新数据：在本机采集好，把 `data/gdp.db` 传上去覆盖，然后
`sudo systemctl restart gdp-platform`。

### 路线 D：GitHub Pages 纯静态站（永久网址、不用服务器、不用备案）

GitHub Pages 只能托管静态文件、跑不了 Python，所以本项目提供一条**导出**路线：
把数据库与页面导出成纯静态站点（数据以 JSON 形式随站点发布，`/api/...` 由前端数据层
在浏览器里算出来），静态站上筛选、下钻、分页、图表、导出 CSV 都照常可用，只是不能采集。

```bash
python deploy/export_static.py     # 生成 dist/（9 个页面 + 24 份区域视图 + 数据包，约 8 MB）
python deploy/verify_static.py     # 可选：验证静态版与后端结果逐条一致（34 个查询）
cd dist && python -m http.server 8100   # 本地预览 http://127.0.0.1:8100/
```

然后把 `dist/` 里的内容传到 GitHub 仓库并开启 Pages，网址形如
`https://<你的用户名>.github.io/<仓库名>/`。逐步操作（含网页上传、命令行推送、
发布后自检清单，以及数据更新后如何重新发布）见
[`发布到 GitHub Pages 操作指南.md`](发布到%20GitHub%20Pages%20操作指南.md)。

适用场景：想要一个**永久、不用维护服务器、关机也不失效**的网址发给同学或老师。
代价：数据是导出时的快照，不更新就不会变；美国县级数据为控制体积只导出每个县最新一年。

### 路线 C：只想先给同学看一眼 —— 本机 + Cloudflare 隧道（5 分钟，不用服务器）

连服务器都不用买，自己的电脑开着就是一个站点，而且可以挂**自己的域名**：

```bash
# 1. 本机以公共演示模式启动（Windows 双击 deploy/start_public.bat 等价）
GDP_PUBLIC=1 GDP_HOST=0.0.0.0 GDP_PORT=8000 python wsgi.py

# 2. 另开一个窗口，装 cloudflared 后起一条隧道（Cloudflare 免费）
#    Windows: winget install --id Cloudflare.cloudflared
cloudflared tunnel --url http://127.0.0.1:8000
#    它会打印一个 https://xxxx.trycloudflare.com 地址，立刻就能发给同学
```

想把 `xxxx.trycloudflare.com` 换成自己的域名，用一条**命名隧道**（免费）：
`cloudflared tunnel login` → `cloudflared tunnel create gdp` →
`cloudflared tunnel route dns gdp gdp.你的域名.com` → `cloudflared tunnel run gdp`。
域名 DNS 托管在 Cloudflare 时最顺（把域名的 NS 指到 Cloudflare 即可，不必备案）。

> 代价：电脑必须开着，`python wsgi.py` 与 `cloudflared` 两个窗口都不能关。
> 适合答辩前临时演示；长期挂建议走路线 A 或 B。

## 三、部署相关文件一览

| 文件 | 用途 |
| --- | --- |
| `wsgi.py` | 生产入口（gunicorn / waitress / 平台 WSGI 服务器加载它）；直接 `python wsgi.py` 也能起服务 |
| `requirements-server.txt` | 部署多装一个 `waitress`（纯 Python，Windows/Linux 通用） |
| `deploy/Dockerfile` | 通用镜像，任何支持 Docker 的平台/NAS 都能跑 |
| `deploy/render.yaml` | Render 蓝图（免费档 + 公共演示模式 + 新加坡节点） |
| `deploy/Procfile` | Railway / Heroku / Zeabur 这类平台自动识别 |
| `deploy/nginx.conf.example` | 云服务器方案的反向代理配置（含静态文件直发） |
| `deploy/gdp-platform.service` | systemd 托管单元（开机自启 + 崩溃重启） |
| `deploy/start_public.bat` | Windows 一键以公共演示模式启动 |
| `deploy/export_static.py` | 导出纯静态站点到 `dist/`（GitHub Pages 等静态托管用） |
| `deploy/verify_static.py` + `static_parity_check.js` | 静态站等价性验证：前端数据层与后端逐条比对 |
| `.dockerignore` | 构建镜像时排除说明书、分页图、node_modules 等大件 |

环境变量（写在平台后台或 `.service` 文件里，**不需要改代码**）：

| 变量 | 作用 | 建议值 |
| --- | --- | --- |
| `GDP_PUBLIC` | 公共演示模式：只读快照，关闭采集与补录入口 | 公网部署填 `1` |
| `GDP_HOST` | 监听地址 | 容器/服务器填 `0.0.0.0`，Nginx 后就填 `127.0.0.1` |
| `GDP_PORT` | 监听端口 | `8000`（平台若注入 `PORT`，以 `PORT` 为准） |

## 四、常见问题

**Q：部署后打开提示“数据库还没有数据”？**
`data/gdp.db` 没有跟着一起上传（多数平台的 `.gitignore` 或网页上传会漏掉大文件）。
确认仓库里包含 `data/gdp.db`，或者把本地导出的 `data/dataset/*.csv` 一并上传后重新部署。

**Q：为什么数据集页没有“一键更新数据”？**
这是公共演示模式的预期行为（见本文第一节）。本地运行时它是正常的。

**Q：能不能让老师在线触发采集，看爬虫跑起来？**
不建议在公网开放。演示爬虫请用本地版本（`python -m spider.pipeline`，命令行会实时打印
每个数据源的入库行数、耗时与重试次数），或者用桌面控制台 `python gui/console.py` 现场演示。

**Q：免费平台打开很慢 / 第一次要等十几秒？**
免费实例会休眠，第一个请求负责唤醒它。想让老师打开就是秒开：验收前 5 分钟自己先访问一次，
或者改用路线 B（云服务器）或路线 C（本机隧道，电脑开着就不休眠）。

**Q：域名解析加了但打不开？**
依次检查：`ping gdp.你的域名.com` 是否解析到预期 IP；国内服务器是否已完成备案；
服务器安全组/防火墙是否放行 80 与 443；`sudo nginx -t` 与 `sudo systemctl status gdp-platform`
是否都正常。

**Q：怎么更新公网上的数据？**
本地跑一次采集（`python -m spider.pipeline`）→ 把 `data/gdp.db` 提交到仓库或上传到服务器 →
平台重新部署 / `sudo systemctl restart gdp-platform`。页面顶部的「只读快照」时间会随之更新。

**Q：`https` 证书到期怎么办？**
certbot 装好后会自动续期（systemd timer），可用 `sudo certbot renew --dry-run` 演练一次。
