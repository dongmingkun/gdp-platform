本次沿用原项目的 Python、Flask、SQLite 与 ECharts 架构，保留现有数据库及原始数据。教师提供的文件是报告模板，未另列功能评分标准。

## 本次修改

| 问题 | 修改后的行为 |
| --- | --- |
| 首页把天津显示为增速最低城市 | 正确显示样本中最低的佛山市 −1.53%；注明增速仅覆盖 34 / 336 个城市 |
| 人均增长卡误用了 GDP 总量倍数 | 人均 GDP 为 1990 年的约 43.5 倍，总量约为基年的 53.9 倍；文字统一用“变为/为基年的” |
| 人均入口仍按总量排序 | 新增独立人均排行，贯穿数据库、API、图表、CSV 与静态站 |
| 把城市人均 GDP 当作收入分类 | 改为人民币产出区间：低于 5 万、5 万至不足 10 万、至少 10 万；说明不等同于居民收入 |
| 缺年记录也被算作同比 | 仅比较连续年份；没有上一年数据时跳过 |
| 多国折线按数组位置对齐 | 使用共同年份轴；缺年填空并断开折线 |
| 首页城市图默认使用美元格式 | 正确显示人民币；美国、日本人均明细分别显示美元、日元 |
| 切换数量或年份后丢失指标 | 表单保存当前指标；静态按钮与本地版一致 |
| 空库、单个城市、缺人均数据引发页面错误 | 显示缺数据提示；无数据的国家不再被误标成第 1 名 |
| 全新环境缺少 lxml 无法启动 | 明确运行依赖，开发依赖另列；启动脚本安装失败时停止并说明 |
| “关于”页仍说只有两种数据源、四张表 | 更新五种来源及五张表，区分官方、转载与人工整理 |
| 报告写前十城市约占三分之一，附带未经证明的原因 | 更正为样本 GDP 合计约 23.8%，去除没有证据的因果解释 |

## 运行与复现

```powershell
python -m pip install -r requirements.txt
python run.py

# 测试和重新生成报告
python -m pip install -r requirements-dev.txt
python deploy/export_static.py
python docs/collect_evidence.py
node docs/docbuild/generate_report.js
# Windows 已安装 Word 时，可更新目录并导出 PDF
./docs/render_report.ps1
```

报告生成器还需要 `docs/docbuild` 内的 Node 依赖：首次使用可在该目录运行 `npm install`。网页截图需要先启动服务再执行截图脚本；报告生成本身不会自动更新截图。

本次验证记录：`docs/validation.json`（环境、数据规模、测试）；`docs/browser-validation.json`（浏览器页面与切换流程）。本次干净虚拟环境仅安装运行依赖后，九个页面均返回 200，`pip check` 通过。

## 提交与线上更新

- 本地运行入口为根目录 `run.py`，静态发布文件位于 `dist/`，发布仓库中的 Python 源码位于 `dist/source/`。
- GitHub Pages 运行静态 HTML、JavaScript 与 JSON 数据包；Python 采集和数据库功能需本地运行。
- 发布时提交并推送 `dist/` 发布仓库的 `main` 分支，再等待 GitHub Pages 构建；线上内容以最新成功部署的版本为准。
- 原始城市榜单缺少完整视频链接，尚未逐条核验各地统计公报。这是数据证据的限制；程序测试通过不代表原始榜单已经核实。
