# GDP 平台 · 静态演示站点

这是「全球 GDP 数据采集与可视化分析平台」的**静态导出站**，用于挂到 GitHub Pages
等只能托管静态文件的平台。数据快照时间：2026-10-17 14:22:12。

## 内容

- 9 个页面：总览、城市格局、全球排行、趋势分析、国家对比、份额变化、中国季度、数据集、关于
- 数据包：`data/*.json`（由 SQLite 导出），页面里的图表与筛选由前端 `static/js/static-api.js` 计算
- 数据文件：`data/dataset/*.csv`（可直接用 Excel 打开）

## 与在线版的差别

- **只读快照**：不能采集/补录数据（需要更新时在本地跑 `python -m spider.pipeline` 后重新导出）
- 区域页预生成了常用视图（快捷视图、各年份、各显示数量），筛选控件会跳到最接近的那一份
- 区域页的“筛选区域”在静态版里只筛当前表格已列出的行
- 县级数据只包含每个县的最新一年（数据量考虑）

## 重新导出

```bash
python deploy/export_static.py --out dist
cd dist && python -m http.server 8100   # 本地预览 http://127.0.0.1:8100/
```
